É uma calculadora simples. Você digita dois números nos campos e clica em um dos três botões com símbolos de somar, subtrair ou multiplicar. O resultado aparece 
embaixo. Cada botão tem uma cor diferente pra ficar fácil de identificar: verde pra soma, vermelho pra subtração e azul pra multiplicação. Se esquecer de preencher algum campo, ela avisa em vermelho. só o básico funcionando.
